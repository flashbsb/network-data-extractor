📖 Dijkstra Path Analysis Legend

Path Score: A quality index from 100/100 evaluating path health:
  • Link physically DOWN: Deducts 50 points (marked as Link Down).
  • Link has 100% loss (FAIL): Deducts 40 points.
  • Packet Loss: Deducts 3 points per % of packet loss.
  • Latency: Deducts 10 points if average latency exceeds 200ms.
